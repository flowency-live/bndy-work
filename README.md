# bndy-work

The bndy workboard: initiatives and backlog as issues in this repo, shown on the [@bndy-work Project](https://github.com/users/flowency-live/projects/1).

- An initiative is an issue labelled `initiative` and `lane:<id>`. Its body holds the objective and the Now and Next task lists.
- A backlog item is a sub-issue of its initiative, labelled `lane:<id>`, with Status, Lane and Rank on the Project.
- Agents follow [WORKBOARD.md](WORKBOARD.md) before reading or changing anything here.

This repo is public. Never put secrets, personal data or details of unfixed security weaknesses in issues or comments.
